Scoring model

The project separates raw dimensions from persona weighting so the same tool can rank differently for CISO, AppSec, Red Team, MLOps, PM, startup builder, agent architect, or MCP security reviewer.

Persona score formula persona_score = weighted_average(selected_dimension_scores, persona_weights) × 20

Raw dimensions use a 1–5 scale. Persona score is normalized to 0–100 for easier comparison.

Agentic Readiness Score

Use this score when selecting tools for autonomous agents, multi-step workflows, tool execution, delegated tasks, or production agent runtime control.

MCP Security Score

Use this score when reviewing MCP clients, third-party MCP servers, tool permissions, server inventory, tool output sanitization, sandboxing, and MCP supply-chain exposure.

How to update and maintain

1. Add or edit a tool

Edit data/tools.json. Keep each score between 1 and 5 and add a short maintainer_notes field explaining caveats.

2. Map Agentic OWASP / ASI

Add agentic_owasp, agentic_scores, and mcp_scores. Prefer conservative scoring unless the tool has evidence for runtime enforcement, MCP coverage, or agent identity controls.

3. Validate before commit

Run a JSON parse check, then open index.html locally. For larger projects, add a GitHub Action that validates schema, detects missing fields, and checks links.

4. Deploy to Hugging Face

Create a Hugging Face Space, choose Static SDK, and commit README.md, index.html, styles.css, app.js, and data/tools.json.
